# Printed and re-captured test pages

15 pages from the test split with automatic symbol labels (`print_list.csv`).
Each page is printed on A4 and captured twice:

- `scanner/NN.jpg` (or .png): flatbed scan, 300 dpi
- `phone/NN.jpg`: phone photo

`NN` is the `image` column of `print_list.csv` (page number in the print set).
